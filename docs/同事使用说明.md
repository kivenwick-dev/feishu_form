# 同事使用说明（零基础版）

> 如果你拿到的是一个打包好的程序文件（Windows 叫 `feishu-web.exe`，Mac/Linux 叫 `feishu-web`），照着本文做即可。
> 不需要安装任何软件，也不需要填写账号密码。

## 一、你会收到什么

一个文件：

- Windows：`feishu-web.exe`
- Mac：`feishu-web`
- Ubuntu：`feishu-web`

把它放到桌面，或者任意一个你找得到的文件夹。

## 二、怎么打开

### Windows

1. 双击 `feishu-web.exe`；
2. 如果弹出「Windows 已保护你的电脑」，点「更多信息」→ 点「仍要运行」；
3. 稍等几秒，会自动打开浏览器页面。

### Mac

1. 把文件放到桌面；
2. 打开「启动台」→「其他」→「终端」；
3. 在终端里逐行输入下面三条命令，每行按一次回车：

```bash
cd ~/Desktop
chmod +x feishu-web
./feishu-web
```

4. 如果提示「无法打开 feishu-web，因为 Apple 无法检查它是否包含恶意软件」，先执行下面这条，再重新 `./feishu-web`：

```bash
xattr -dr com.apple.quarantine feishu-web
```

### Ubuntu

```bash
cd ~/下载
chmod +x feishu-web
./feishu-web
```

### 打开后

浏览器会自动出现一个页面。如果没有自动打开，手动在浏览器地址栏输入：

```text
http://127.0.0.1:8765
```

> 那个黑色的窗口不要关，关掉程序就退出了。用完后可以关掉窗口结束。

## 三、在网页上怎么操作

从上到下依次填：

1. **飞书表格链接**：把线上你需要统计的表格链接（`https://...feishu.cn/wiki/...`）粘贴进去；
2. **本地 Excel 文件**：从线上表格转化一份本地的Excel；
3. **截图 PDF 图片尺寸（毫米）**：不用管，保持默认 180 × 260；
4. **输出目录**：点「选择目录」，挑一个你想保存结果的位置（比如桌面）；
5. 点 **开始归档**。

下方会滚动显示进度，最后出现“完成”就说明好了。

## 四、结果在哪里

打开你刚才选的输出目录，会看到一个以表格名字命名的文件夹，里面每位同事一个文件夹：

```text
表格名字/
├── 张三/
│   ├── 发票/          ← 该同事的发票文件
│   ├── 截图/          ← 该同事的截图
│   ├── 截图.pdf       ← 截图合并成的一个 PDF
│   └── 报销信息.txt   ← 该同事的文字信息
├── 李四/
│   └── ...
├── 汇总.txt
└── 表格名字.zip       ← 整个结果的压缩包
```

把 `表格名字.zip` 或整个文件夹交给需要的人即可。

## 五、遇到问题

- **页面没打开**：先确认黑色窗口还开着，再手动访问 `http://127.0.0.1:8765`；
- **提示“请输入飞书表格链接”**：链接没粘贴，或粘贴的内容不完整；
- **提示“选择目录”无反应（Ubuntu）**：直接在输入框里手打一个路径，例如 `/home/你的用户名/Desktop`；
- **其它报错**：把页面下方的日志和报错截图发给维护这个工具的人。

## 六、注意事项

- 这个程序里已经带了账号信息，只在自己电脑上使用，**不要**转发到公开群、网盘或互联网；
- 程序只会读取飞书表格，不会修改、删除或上传线上数据；
- 报销数据属于敏感信息，生成的结果不要随意转发。
